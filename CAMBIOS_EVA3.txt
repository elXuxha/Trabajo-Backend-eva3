MAPPEO DE ENTIDADES DEL CASO:
  Categoria    -> catalog.Category
  Producto     -> catalog.Product
  Cliente      -> accounts.User (user_type='customer')
  Venta        -> orders.Order
  DetalleVenta -> orders.OrderItem

LAS 20 CONSULTAS EXACTAS DEL INFORME (implementadas en reportes/views.py):
   1. Todos los productos disponibles            -> filter(is_active=True)
   2. Productos de una categoria seleccionada    -> filter(category_id=...)
   3. Productos dentro de un rango de precios    -> filter(price__gte/lte)
   4. 10 productos mas caros                     -> order_by('-price')[:10]
   5. Total de clientes registrados              -> filter(user_type=...).count()
   6. Compras de un cliente especifico           -> Order.filter(user_id=...)
   7. Productos de una venta determinada         -> OrderItem.filter(order_id=...)
   8. Ventas en un periodo seleccionado          -> filter(created_at__date__gte/lte)
   9. Productos con menos de 5 unidades          -> filter(stock__lt=5)
  10. Monto total vendido en un dia              -> filter(created_at__date).aggregate(Sum)
  11. 5 productos mas vendidos (unidades)        -> values().annotate(Sum('quantity'))[:5]
  12. 5 clientes con mas compras                 -> annotate(Count('orders'))[:5]
  13. Monto total comprado por cada cliente      -> annotate(Sum('orders__total'))
  14. Productos nunca vendidos                   -> filter(orderitem__isnull=True)
  15. Promedio gastado por venta                 -> exclude('cancelled').aggregate(Avg)
  16. Categoria con mayor monto de ventas        -> values().annotate(Sum(F*F))[:1]
  17. Unidades vendidas por producto ultimo mes  -> filter(order__created_at__date...) + TruncMonth-free Sum
  18. Cliente que mas gasto en el ano            -> filter(orders__created_at__year).annotate(Sum)
  19. Distribucion de montos por mes del ano     -> annotate(TruncMonth).values().annotate(Sum, Count)
  20. 10 productos con mayores ingresos          -> values().annotate(Sum(F('quantity')*F('product_price')))[:10]

TODAS usan EXCLUSIVAMENTE el ORM: filter, values, select_related, count,
annotate, aggregate, Sum, Count, Avg, F, Q y TruncMonth.
NO se usa SQL crudo: cero .raw(), .extra(), cursor() o connection.execute().
(Unico acceso a bajo nivel en el proyecto: los PRAGMAs SQLite del comando de
inyeccion, que el enunciado exige expresamente.)
